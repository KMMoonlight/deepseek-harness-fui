# 07 — 自有布局骨架替换 ui-layout

**What to build:** 用自己的 FUI 布局替换官方布局插件，接管应用主框架（侧栏、主区、状态条）。这是"布局自己调"这个目标的正式落点。

一个容易漏的职责交接：官方布局插件除了排版，还负责把解析后的主题快照施加到文档根节点上。替代品必须接管这件事，否则主题会整体失效 —— 而且失效方式不明显，容易到很后面才发现。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 自有布局插件在 roster 中替换官方布局插件，官方包已从组装中移除而非静默保留
- [ ] 主框架为自有实现，视觉符合 FUI 风格
- [ ] 保留的会话、轨迹、工具等插件通过 slot 正常挂载并渲染
- [ ] 主题快照仍能正确施加到文档根节点
- [ ] 会话切换、窄窗口下的布局退让、键盘焦点可见性均正常
- [ ] 减少动效偏好被尊重
